# Cutline Studio

A phone-first sports editing prototype. A configured Gemini Coach can analyze a **public YouTube video link**, suggest approximate moments, summarize what it observes, explain visible editing choices, and propose hooks, titles and hashtags. The browser editor can then trim an **authorized local copy of the same video**, make a vertical cut, mix local audio, and export it.

**Important:** A link is not a video file or permission to reuse footage. Cutline does not download YouTube videos, directly connect to TikTok's sound catalog, automatically post to TikTok, or make a finished edit from a link alone. AI may miss fast action or produce incorrect timestamps and claims; review everything and use footage and music you have rights to use.

## Using the workflow

1. Open your privately protected Cutline site over HTTPS. In **AI Coach**, paste a public YouTube link in your message, or use the optional video field to keep the link attached for follow-up questions. The field remains in the current tab until cleared; every confirmed Gemini request sends it again and can use quota or incur charges. Google supports public, not private or unlisted, YouTube videos.
2. Read the confirmation and approve each request. Your message, link and up to six recent chat messages go to Google Gemini. The link is analyzed remotely; no source video is downloaded to this app. If AI is not configured or the provider cannot analyze the video, the app reports that instead of inventing an analysis. **Test selected AI** sends a short test prompt only after confirmation: it does not send your chat or video and may use quota. A successful test verifies that the selected text provider replied, not that video analysis, Search, TikTok or a particular edit will work. You can cancel a request; the provider may still charge for work already started.
3. Check the summary and approximate suggested moments. Choose **Use this moment in editor** for a single trim, or **Build timeline from these moments** when multiple suggestions are available. Select your authorized local copy of the **same full video** and confirm the match. The latter replaces the current cut list in the suggested story order; check every timestamp and reorder, shorten or remove cuts. Cutline cannot verify the files are the same, and AI can miss quick action. If no reliable moments are returned, make the cuts manually. **Take a closer look** prepares an optional focused follow-up around a suggestion; review and send it separately.
4. For fast action, optionally turn on **Take a closer look at a fast play** and enter the original video's start and end as `MM:SS`, `HH:MM:SS`, or whole seconds (up to 90 seconds). After confirmation, Gemini is asked to sample that interval at 3 frames per second instead of its normal default. This may use more quota, cost more or take longer, and can still miss action. The server discards suggested editor ranges outside the chosen interval, but cannot verify the remaining timestamps; check them against the full original. Focus remains selected until you turn it off.
5. Gemini may propose an editable **edit recipe** with a headline, color, zoom, text style or speed. Choose **Review & apply Gemini edit recipe** and approve the displayed settings before they change the editor; Gemini does not edit or download the video by itself. Speed applies only to the selected timeline cut (Undo cut can restore it), or to the current trim when no cuts exist. The other look controls apply to the whole edit. A recipe may not be returned for every request.
6. In **Edit workspace**, set in/out points on the source and tap **Add trim to timeline**. Up to **12 cuts from the same source video** can be selected, updated, split at the playhead, moved, duplicated or removed. Choose speed per cut, and use cut-list undo/redo. **Preview timeline** plays them in order; export uses the cut list when present or the current trim when it is empty. Hard cuts and a short fade through black are available. The source scrubber is separate from the edit timeline; changing a selected cut's in/out or speed requires **Update selected cut**.
7. Adjust framing, color, text and sound. Controls include 9:16/1:1/16:9, fill/fit, zoom, pan, rotate, flip, a start-to-end animated zoom, color presets, brightness, contrast, saturation, vignette and whole-edit fades. Mix source and added audio; the headline and supporting line have independent show/hide times in **finished-edit seconds**. Choose text font/case, colors, headline position and entrance. Preview and export share the canvas renderer. These controls are global to the edit except for each cut's range and speed. This is not a full multi-track editor: separate source videos, automatic speech captions, motion tracking, masks and advanced keyframes are not implemented.
8. Use **Save project file** to download a JSON file with the cut list, editor settings, and source/audio filenames and source metadata. It contains **no video, audio or API keys**, but can contain your text and filenames; store it privately. To reopen, choose the original local source video first, then **Open project file**, and re-add any licensed music. The app warns when filename, size or duration differ, but these checks do not prove the video matches. Keep the actual media files separately; no cloud copy is created. Undo/redo covers cut-list changes only and resets when a project opens.
9. Add a separate local audio file you are licensed to use, or save the video first and use **Add sound** inside TikTok. [TikTok's Commercial Music Library](https://ads.tiktok.com/business/creativecenter/music/pc/en) and [usage guidance](https://ads.tiktok.com/help/article/how-to-use-the-commercial-music-library) can help you choose music for the right account, region and use. Cutline is not connected to the TikTok catalog; finding a song does not grant rights outside its license.
10. Tap **Export current edit**, keep the page open while it renders, preview the **entire** result and choose **Download edit** or **Share / save**. The combined source ranges and the planned edit timeline must each be **60 seconds or less**; long timelines must be shortened before export. The recorded file can be slightly longer because of encoder buffering and any pauses. Balanced quality uses a 540-pixel short side for multi-cut sequences and 720 for a single trim; 540 or 720 can also be selected. Rendering is real time and asks for up to 24 frames per second, but slow devices can drop frames or briefly pause between cuts. The recorder holds the final frame for about half a second to allow encoding to finish. Check the video, timing and sound before posting. The output is not stored in the cloud. Multi-cut exports prefer WebM where supported; a browser may instead produce MP4. The selected container and codecs may not be accepted by TikTok, even when the extension is `.mp4`.

Titles and hashtags are **creative suggestions, not a promise of virality or evidence of a current trend**. Without the optional Google Search feature below, the Coach does not do live research. For TikTok-specific trends, also check [TikTok Creative Center](https://ads.tiktok.com/creative/creativeCenter/trends) and its [Creator Search Insights guidance](https://support.tiktok.com/en/using-tiktok/growing-your-audience/creator-search-insights).

## Run locally

Node.js **20 or newer** is required. The local editor needs no npm packages or AI key:

```sh
npm start
```

Open `http://localhost:4173`. The server honors `PORT` (default `4173`) and `HOST` (default `0.0.0.0`); for a local-only process, set `HOST=127.0.0.1`. Run the automated server and timeline tests with `npm test`.

Optional real-browser smoke tests are in `scripts/browser-smoke.cjs` and `scripts/arena-coach-smoke.cjs`. Both need a separately installed `puppeteer-core` and Chromium/Chrome; these are test tools, not production dependencies. Set `NODE_PATH` to that installation's `node_modules` and `CHROME_PATH` to the browser executable. The first test also needs an `ffmpeg` build with `lavfi`, `libvpx-vp9` and `libopus` (set `FFMPEG_PATH`); it synthesizes media and measures a multi-cut export. The Arena test checks provider selection, explicit consent and mobile layout. Run them with `node scripts/browser-smoke.cjs` and `node scripts/arena-coach-smoke.cjs`. Both use mocked providers and do not verify a real phone or live API.

Without an access password the local app is open to anyone who can reach it, and all AI routes remain **off**. Do not expose an unprotected personal preview to the internet.

### Browser-only fallback preview

For a quick look when the live sandbox is unavailable, the public branch can be opened through the third-party [HTML Preview service](https://htmlpreview.github.io/?https://github.com/DMLROCK/Cutline-Studio/blob/arena/ae97be88-cutline-studio/index.html). This is not the hosted Node app: AI, research, TikTok and server APIs are unavailable. It can load the browser editor, but codec/export support depends on the device and service. Because the page is delivered through a third party that controls its own code, do not enter secrets or use confidential media there; use a non-sensitive test clip. For actual AI, deploy the private Node app below.

## Set up a private hosted preview and AI

Import the **`arena/ae97be88-cutline-studio` branch** as a Node service on a host that supports Node 20+, HTTPS, runtime secrets, and a long-running web process. Set the start command to `npm start` and configure the host's assigned `PORT` if it doesn't set one automatically. GitHub stores the code; it is not itself an always-on hosting service.

In the hosting provider's **runtime environment variables / secrets** (not in a repository file, browser page, screenshot or chat), first set the password and verify the login, then add the providers you want:

| Variable | Value / purpose |
| --- | --- |
| `CUTLINE_ACCESS_PASSWORD` | A unique random **16–256 character** private password. Mark it secret. |
| `ARENA_API_KEY` | Your Arena API key, permitted for use by this application. Mark it secret. Manage keys at [Arena API keys](https://platform.arena.ai/dashboard/keys). |
| `ARENA_MODEL` | Exact model identifier enabled for the key in your Arena workspace. |
| `CUTLINE_ARENA_ENABLED` | `true` to enable Arena text coaching. |
| `GEMINI_API_KEY` | For video analysis, your Google Gemini API key. Mark it secret. Obtain/manage one at [Google AI Studio API keys](https://aistudio.google.com/apikey). |
| `CUTLINE_AI_ENABLED` | `true` to enable Gemini Coach and confirmed per-clip AI review. |
| `GEMINI_MODEL` | Optional; defaults to `gemini-3.8-flash`. Use a model your Google project can access that supports video. |

Arena's app-authorized API access and eligible models depend on the account/workspace. Arena states that **free-router keys work in the Claude Code app only**; do not assume a free coding-router key or ordinary Arena chat access works in Cutline. Review access, quotas, terms and possible charges before use.

The server reads these at startup and does **not** load `.env` files automatically. Restart/redeploy after changes. Open the HTTPS address in a private browser window and verify the login prompt **before** adding or enabling an API key. Username: `cutline`; password: your private `CUTLINE_ACCESS_PASSWORD`. If a password variable is present but invalid or empty, all routes fail closed. If it is absent, the app opens without a login and AI remains disabled.

The **configured** badges and `/api/health` describe settings only; they do not validate your key, account, model, provider connection, quotas, or a real video. The consented **Test selected AI** button can verify a simple text reply from the selected provider. Only a separate actual video request on your deployment can verify video analysis. Google’s [terms](https://ai.google.dev/gemini-api/terms), privacy rules, quotas and possible charges apply; content submitted through unpaid services may be used to improve Google products. Check your actual [Google rate limits](https://aistudio.google.com/rate-limit?timeRange=last-28-days) and billing settings. Google documents up to eight hours of public YouTube video per day on the free tier, subject to other limits and availability; that is **not** a guarantee of unlimited daily use. Long videos and fast sports action may require more processing, and the default static video sampling can miss key frames. Provider requests can time out.

The shared-password gate is for a small personal preview, **not** multi-user production authentication. Use HTTPS: HTTP Basic credentials would otherwise be exposed. Anyone with the password can spend the configured API quota. The in-memory login throttle, one-at-a-time Coach limit and five-second peer cooldown are lightweight safeguards, not per-user billing controls; they reset on restart and can group visitors behind a proxy. Add proper accounts, quotas, durable abuse protection and budget controls before public use.

### If you use the existing Suga preview

Suga's documentation describes the following setup, but the existing service's branch, settings and deployment have not been verified. Its canvas was difficult to operate on a phone; a laptop may make selecting the service easier. Do not delete the existing service.

1. Open the project and select the existing `cutline-studio` service. In **Config**, check its GitHub repository is `DMLROCK/Cutline-Studio` and its watched branch is `arena/ae97be88-cutline-studio`. The Node start command is `npm start`; Node 20 or newer is required.
2. In **Config → Public Networking**, add or check the **Generated URL** HTTPS endpoint. Set its target port to `4173`. In **Env Vars → Edit environment variables**, set `PORT` to `4173` and add `CUTLINE_ACCESS_PASSWORD` with a unique random password of 16–256 characters. Mark the password **Sensitive** before saving. **Save**, then **Apply** the environment changes.
3. Open the generated HTTPS URL in a private browser window. It should ask for username `cutline` and your password. If it does not ask, stop: verify the deployment, branch and protection before adding a key.
4. In your [Arena API workspace](https://platform.arena.ai/dashboard/keys), check that it permits API use by Cutline and identify an enabled model. Return to **Env Vars → Edit environment variables**. Add `ARENA_API_KEY` using your own key and mark it **Sensitive**; add `ARENA_MODEL` with the permitted model ID and `CUTLINE_ARENA_ENABLED` with the value `true`. Save, then **Apply**. Never put keys in source code, the static preview, chat, or a screenshot.
5. Open the Suga URL again, sign in, go to **Coach**, and tap **Test selected AI** with **Arena · text only** selected. Confirm the text-only test and watch for provider errors or quota limits. This does not test video analysis.
6. For YouTube analysis, optionally return to Suga's environment settings, add a **Sensitive** `GEMINI_API_KEY` and `CUTLINE_AI_ENABLED=true`, then Save and Apply. In Coach, choose **Use Arena + Gemini for a video**, paste a public link and review the confirmation. Gemini examines the video; Arena receives Gemini's text and supplies creative direction. Providers can charge separately.

Provider screens and plans can change; this workflow, real Gemini calls, Suga's request limits, memory needs, and Hetrix behavior have not been tested on that service. A small memory allocation may not support the separate 14 MiB upload-review route.

## Optional live Google Search research

Search is **off by default**. Google's Gemini API Search grounding is a paid service and can incur separate charges, including multiple searches; availability varies by model and account. Do not enable it unless the owner has reviewed the [pricing](https://ai.google.dev/gemini-api/docs/pricing) and accepts possible charges.

To make the checkbox available, set `CUTLINE_RESEARCH_ENABLED=true` on the protected, Gemini-enabled server and restart it. The checkbox starts unchecked; selecting it and confirming the request explicitly adds a **second** Gemini call for research. The result displays provider-returned sources and citations, plus Google's required Search Suggestions when supplied. They are retained only in the current tab, not long-term chat storage; after reload the user must run research again. For safety, unrecognized or unsafe suggestion HTML causes the research result to be withheld rather than executed or displayed without its required suggestions. No actual paid Search request has been verified by this repository's mock tests. A source link does not mean every claim is verified or that a title or sound is currently trending.

## Arena text coach and creative director

YouTube video analysis uses Gemini. Arena is **not automatically connected** to this Agent Mode session or its credentials. If you have separately authorized access to Arena's developer API and a compatible model, you can optionally set these runtime values on the same protected server. Gemini is optional for standalone Arena text chat, but is required for YouTube video analysis and Google Search research:

- `CUTLINE_ARENA_ENABLED=true`
- `ARENA_API_KEY` — a separate runtime secret; never put it in code or chat.
- `ARENA_MODEL` — the model identifier your Arena developer workspace explicitly permits.

In AI Coach, **Arena · text only** is selected by default when Arena is configured (no Gemini call). When both providers are configured, choose **Use Arena + Gemini for a video**, or select Gemini mode and check **Arena creative director + edit recipe**, to add an Arena call after Gemini. The second provider is never enabled automatically. Each request needs confirmation. Arena receives the current message and up to six recent chat messages; in the Gemini-plus-Arena mode it also receives Gemini's text answer, via `https://api.arena.ai/v1/chat/completions`. Ask it for a storyboard, hook, caption package, sound direction or edit ideas. It can also suggest a limited recipe using controls this editor actually has; you review the proposed settings and explicitly choose whether to apply them. If the model does not return a valid recipe, the text can still be shown. Arena receives **text only**; it does not independently watch the video, hear audio, fetch TikTok sounds or research trends. Separate access restrictions, quotas, terms and possible costs apply; some Arena routers are limited to particular developer clients. Configuration is not a successful connection test, and the adapter has only been tested with a mock provider.

## Optional TikTok creator profile and shared stats

This is **off by default**. It is an optional, single-process personal-preview integration, not general-purpose multi-user account management. Without setup, the Studio and Creator profile show dashes rather than invented numbers. A real TikTok developer app, TikTok approval, a public HTTPS host, private durable storage, and each TikTok account owner's consent are required. TikTok can deny an app or a requested scope; this code and the mock tests do not guarantee approval or a working live connection.

### Setup

1. Create a developer account and app at [TikTok for Developers](https://developers.tiktok.com/). Add **Login Kit** and the appropriate TikTok API/Display product; request `user.info.basic`, `user.info.profile`, and `user.info.stats`. Complete TikTok's required domain verification, privacy-policy/terms, app review and any other current requirements. Consult [Login Kit for web](https://developers.tiktok.com/docs/en/login-kit-web), [scopes](https://developers.tiktok.com/docs/en/tiktok-api-scopes), and [Get User Info](https://developers.tiktok.com/docs/en/tiktok-api-v2-get-user-info). Approval is not automatic, and a user may grant only some scopes.
2. Deploy the protected Cutline branch on **one** HTTPS Node process. Choose a persistent private directory **outside the repository checkout** (for example, a host-mounted private volume at `/var/lib/cutline-tiktok`). The service must be able to create files there. A temporary or ephemeral filesystem can lose connections and public links at restart/redeployment; do not assume a free host supplies durable storage. The integration does not support multiple server instances sharing the same file.
3. In TikTok's Login Kit configuration, register exactly `https://YOUR-HOST/api/tiktok/callback`, replacing `YOUR-HOST` with your actual app's HTTPS hostname. Use the same URL in the server setting below; do not include a query string or fragment. TikTok's consent and callback must complete in the same browser session.
4. Keep the existing strong `CUTLINE_ACCESS_PASSWORD`; then add the following **runtime environment variables/secrets** on the host, not in GitHub, source files, screenshots or chat. Never ask another person to send you their API credentials:

   | Variable | Value / purpose |
   | --- | --- |
   | `CUTLINE_TIKTOK_ENABLED` | `true` to enable the optional integration. |
   | `TIKTOK_CLIENT_KEY` | Client key from your approved TikTok developer app. |
   | `TIKTOK_CLIENT_SECRET` | TikTok client secret. Mark sensitive. |
   | `TIKTOK_REDIRECT_URI` | Exact registered HTTPS URL, e.g. `https://YOUR-HOST/api/tiktok/callback`. |
   | `CUTLINE_TIKTOK_ENCRYPTION_KEY` | A stable, random **64-hex-character** secret (32 bytes). Mark sensitive; see below. |
   | `CUTLINE_TIKTOK_DATA_DIR` | Absolute path to the writable, private persistent directory outside the checkout. |

   Generate a key in a private Node-capable host console or on your own laptop with `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Copy the output directly into the host's secret setting; do not post it in chat. Keep it stable across restarts and store it separately from backups. Losing or changing it makes the encrypted data unreadable. Restrict volume and backup access even though the file is encrypted.
5. Restart/redeploy, sign in to your protected site, open **Creator profile**, and tap **Connect TikTok**. Approve the requested permissions on TikTok and return to the same browser. Configuration status checks settings only; an actual authorization and profile refresh are required to verify the connection. If statistics permission is denied, counts stay blank. If authorization fails, check app/product/scope approval, the exact callback URL and host logs without sharing secrets. Configure the reverse proxy/host **not to log the OAuth callback query string**, which can contain a short-lived authorization code and state.
6. Your private profile and Studio dashboard show authorized TikTok follower, following, **total likes across videos**, and public video counts when available. They refresh on access at most once per 60 seconds per account/process, not continuously in the background. TikTok's counts may lag; the displayed timestamp is when Cutline fetched them, not a guarantee of real-time accuracy. No official LIVE member/subscriber count is integrated. If TikTok cannot confirm a refresh, the owner sees the dated last snapshot and public details are temporarily hidden.
7. Sharing is off initially. Tap **Publish profile**, read the confirmation, then copy or view the generated link. Anyone with that link can see the creator's authorized name, avatar, bio and available counts **without the Cutline password**. Search indexing is discouraged but cannot be guaranteed. Tap **Stop sharing** to revoke the old link; publishing again creates a different link. **Disconnect & delete** removes the stored profile, tokens and public link and attempts TikTok-side revocation. If TikTok cannot confirm revocation, also remove the app in your TikTok account settings.

The server stores access/refresh tokens and snapshots in an AES-256-GCM encrypted file in that directory, uses a secure host-only HttpOnly browser-session cookie and one-use OAuth state, and never sends tokens to profile pages. The browser session expires after 30 days; reconnecting the same TikTok account can recover its share link if its encrypted data still exists. These safeguards are not an independent security review: keep the host patched, use HTTPS, protect the app password, key, volume, backups and reverse-proxy logs, and add proper user accounts, quotas, audit/security controls, a deletion policy and legal review before any broader public service. The site uses a shared password and has no general email/Google accounts or cloud chat sync. No live TikTok developer account or actual TikTok OAuth flow was available for testing.

## Other limits, privacy and hosting

- The separate **uploaded-clip AI review** route requires its own confirmation and accepts supported video types up to **14 MiB**; it sends the selected file to Google. The YouTube-link Coach request does not upload the local source video. The app writes no raw media to its server disk.
- Chats, reference links and theme are stored in the current browser's local storage. Search research is tab-only. Source media, selected audio, export blobs and unsaved edits are temporary; a downloaded project JSON stores settings and filenames only. The optional TikTok connection stores encrypted account data on a private server volume; general accounts, cloud chat sync, durable video storage and direct TikTok posting are not connected.
- Cloady was investigated as a candidate, but this new workflow has **not** been deployed or tested there. Its idle policy, proxy limits, timeouts, Hetrix behavior, actual Gemini use, and rendering performance remain unverified. Local browser rendering uses the creator's device, not a cloud GPU; Google runs the model remotely. Hosting limits and Google quotas are separate. A free host can sleep or change its terms.
- With the password set, unauthenticated `GET`/`HEAD /api/health` return **401**. An uptime monitor configured to accept 401 can check whether the login gate responds, but that does not prove AI, video analysis, export, or the provider are working. Do not assume monitoring prevents a free host from sleeping.

This is a prototype. Test on the actual host, browser and source files before relying on it for daily publishing.
